# Daily Ad Revenue & Performance Tracker

An interactive dashboard built with **Python**, **Streamlit**, and **Plotly** to track and analyze digital advertising revenue, impressions, clicks, and eCPM across publisher websites and ad formats.

Designed for entry-level **Associate – Ad Operations** roles at companies like **VDO.AI (Z1 Tech)**.

---

## 📌 Project Overview

Ad Operations associates monitor ad performance daily to ensure publishers are making the maximum possible revenue. This dashboard solves that exact daily task:
* Tracks daily earnings across different websites (`TechDaily.com`, `NewsPulse.in`, `GamingZone.com`).
* Compares performance between high-impact **Video Ads** and standard **Banner Ads**.
* Calculates key metrics: **CTR (Click-Through Rate)** and **eCPM (Earnings per 1,000 views)**.
* Allows one-click export to **CSV / Excel** for operational reporting.

---

## 📊 Core Metrics Explained Simply

| Metric | What It Means | Formula |
| :--- | :--- | :--- |
| **Impressions** | Total number of times an ad was displayed on screen. | Total count |
| **Clicks** | Total number of times an ad was clicked. | Total count |
| **CTR (%)** | Click-Through Rate: percentage of viewers who clicked. | `(Clicks / Impressions) * 100` |
| **Revenue ($)** | Total money earned in USD. | Sum of dollars earned |
| **eCPM ($)** | Effective Cost Per Mille: revenue per 1,000 ad views. | `(Revenue / Impressions) * 1000` |

---

## 🚀 Key Features

1. **KPI Metric Cards:** Displays Total Revenue, Impressions, Clicks, Average CTR, and Average eCPM in real time.
2. **Interactive Filters:** Filter data by specific websites or ad formats using the sidebar.
3. **Daily Revenue Comparison:** Bar chart showing day-by-day revenue by ad format.
4. **Revenue Share Breakdown:** Donut chart showing the percentage of revenue generated by Video vs. Banner ads.
5. **Website Performance Chart:** Compares total earnings across different publisher websites.
6. **Data Explorer & Export:** Clean data table with a button to download the filtered report as a CSV for Microsoft Excel.

## 🛠️ Tech Stack

* **Python 3.11**
* **Streamlit** (for the web interface)
* **Pandas** (for data processing & calculations)
* **Plotly** (for interactive charts)

## 💻 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/vartika111/ad-ops-performance-dashboard.git
   cd ad-ops-performance-dashboard
   ```
2. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
4. Open `http://localhost:8501` in your web browser.
